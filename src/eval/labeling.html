Eval v2 labeling

For each item decide whether it is a fair evaluation item. Accept: the gold page(s) answer the question (or, for controls, the wiki really has no answer / really conflicts). Accept + add gold: also tick other pages that fully answer it. Reject: wrong, unanswerable, ambiguous or unnatural. Items come with a suggestion from the local model acting as a skeptical judge, unverified ones first. A suggestion is verified when its evidence was checked by code (for example, a claimed answer was found verbatim in a page). Use suggestion copies it; the bulk button confirms only verified ones (spot-check a few). Each label records whether you set it yourself or confirmed a suggestion. Progress is kept in this browser. When done, download labels.json and place it at .cache/eval/v2/labels.json.
