# Insights

Crystallized learnings: observed patterns, active analysis. Written constantly, read selectively.

## Lifecycle

Every insight has a lifecycle:
1. **LOGGED** — observed and recorded
2. **DISPATCHED** — assigned to an agent for action
3. **IMPLEMENTED** — built into a rule, hook, or script
4. **ARCHIVED** — captured but no action needed (with reason)

## By topic

Topics are added as agents notice patterns. Each topic directory has `index.md` with the list.
